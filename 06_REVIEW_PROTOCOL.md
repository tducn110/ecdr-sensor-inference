# Review protocol — current English statement

The review supports the Week 1 research questions and keeps source evidence separate from inference and proposal. The canonical definitions are in [00_OVERVIEW/02_Week_1_Project_Brief.tex](00_OVERVIEW/02_Week_1_Project_Brief.tex).

## Evidence classes

- **Source/runtime:** repository code, configuration, executed logs, retained artifacts, and environment identifiers.
- **Primary literature:** the paper or official documentation that directly supports a literature claim.
- **Inference:** a derivation or interpretation from those sources.
- **Proposal:** an unexecuted hypothesis, planned experiment, or future implementation.

Do not promote file existence, a CI badge, a mock, a label, or a generated PDF into execution or acceptance evidence. Keep reference-decision agreement, classification accuracy, heuristic reuse, formal certification, and system cost as separate quantities.

## Review records

For every promoted claim, retain the source path or primary locator, revision/environment, observation, and status. Use UNKNOWN or PENDING when the required check has not run. The older Vietnamese protocol and dated reports remain historical snapshots and are not rewritten by this current navigation page.
