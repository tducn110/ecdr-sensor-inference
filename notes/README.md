# notes/ — one research note per paper

- Naming: `P<ID>_<ShortName>.md` using IDs from `05_READING_PLAN.md` (P01–P23).
- Template: `05_READING_PLAN.md` §7 (10 sections; never copy the abstract).
- Rule: the moment a note changes a novelty claim, update the ledger in
  `02_LITERATURE.md` and, if needed, `refs.bib` (entry requires URL + quote).
- Status discipline: sections 6 "Verified Claims" only contains quotes with
  page/section locations; everything else stays interpretation.
- These files are version-controlled (unlike `papers/` PDFs, which are gitignored).
